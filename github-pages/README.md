# 桥西夜班 · 首轮验证 Demo

上海网约车生活模拟的网页原型（three.js）。地图取自 OpenStreetMap 上真实的徐汇、静安、长宁交界一带。

**在线试玩**：开启 GitHub Pages（Settings → Pages → main / root）后访问 `https://<用户名>.github.io/<仓库名>/`。
需要通过网址访问，直接双击 index.html 打不开（浏览器禁止本地页面加载模型和贴图）。推荐桌面版 Chrome / Edge。首次加载约 70MB。
